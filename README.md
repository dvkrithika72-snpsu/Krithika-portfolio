## 🌐 About the Project

This is my personal portfolio website, designed and developed to showcase my journey as a Computer Science Engineering student and aspiring Full Stack Developer.

The portfolio brings together my technical skills, projects, academic journey, hackathon experiences, certifications, achievements, and areas of interest in a modern and interactive web experience.

Rather than being a simple static portfolio, this project demonstrates the development of a full-stack application with a responsive frontend, backend architecture, database integration, AI-powered functionality, API integrations, and direct email communication.

The website is continuously evolving as I learn new technologies, build new projects, and improve my development skills.

# 💻 GitHub Integration

The portfolio integrates with GitHub to showcase development work and repositories.

The GitHub integration allows repository information to be retrieved dynamically instead of manually maintaining every repository entry.

Depending on the configured GitHub integration, repository information can include:

- Repository name
- Repository description
- Programming language
- Stars
- Forks
- Repository URL
- Topics
- Last updated information

This helps connect the portfolio with my actual development work.

# 🤖 AI Integration

Google Gemini is integrated into the application to provide AI-powered functionality within the portfolio.

The Gemini API is accessed through the backend rather than directly from the frontend. This helps keep the API credentials secure and prevents sensitive keys from being exposed to visitors.

### AI Integration Flow

```text
User
  ↓
Portfolio Interface
  ↓
Frontend
  ↓
Backend API
  ↓
Google Gemini API
  ↓
AI Response
  ↓
Frontend
  ↓
User

# 🗄️ Database

MongoDB is used as the application's database.

Mongoose is used within the backend to communicate with MongoDB and manage database models.

MongoDB provides persistent storage for application data that requires backend storage.

---

# 🔌 Backend Architecture

The backend is built using Node.js, Express.js, and TypeScript.

It provides the APIs required by the frontend and manages communication with the database and external services.

### Backend Responsibilities

- API handling
- Request validation
- Database communication
- Authentication
- AI API communication
- GitHub API communication
- Application logic
- Security-related middleware
